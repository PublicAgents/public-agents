## Three agent paths, in the vendor's words

**Hosted MCP server**, [introduction](https://docs.ahrefs.com/mcp/docs/introduction): "Ahrefs provides a hosted MCP server that allows users with a Lite plan or higher to connect their Ahrefs account to supported AI tools." The connection URL is `https://api.ahrefs.com/mcp/mcp` (Streamable HTTP). Authorization is "an **authorization consent screen**" after which "the connection will appear in your account with a dedicated **API key** (tagged with `MCP` scope)"; a key can also be generated by hand and sent as a bearer token, which is what the [OpenClaw](https://docs.ahrefs.com/mcp/docs/openclaw) guide does. Keys created through OAuth "default to a monthly limit of 200,000 API units per key." The page's terms section reads: "Using the external MCP endpoint via custom scripts, bridges, or standalone HTTP/JSON-RPC clients is **unsupported and not permitted.** The external MCP server is not a general-purpose programmatic API." That sentence is why no initialize request was sent from here; the `surfaces.mcp` field points at the vendor's tool-categories page rather than the endpoint for the same reason.

[Tool categories](https://docs.ahrefs.com/mcp/docs/tool-categories): "Some MCP clients limit the amount of tools that an MCP server is allowed to advertise. Ahrefs' MCP server goes above this limit for many of them." A `tools` query parameter on the URL selects groups; omit it, the page says, and all tools are advertised. The table lists twenty groups, among them `site-audit` ("Site Audit — projects, issues, page explorer, page content."), `gsc` ("Google Search Console — keywords, pages, positions, and performance history."), `brand-radar-simple`, `rank-tracker`, `keywords-explorer` and `public` ("Public/free endpoints — crawler IP ranges and free domain rating."). A `search-exec` mode advertises `search`, `doc` and `exec` instead of one tool per operation. The tool count behind "all" is not stated on any page read and was not measured.

**REST API v3**, [introduction](https://docs.ahrefs.com/api/docs/introduction): the API is available, the page says, on eligible paid plans. Requests spend units: "The minimum cost for any request is" 50 units, and "Ahrefs API is limited to 60 requests per minute by default." Every response carries its cost in headers (`x-api-units-cost-total`, [limits consumption](https://docs.ahrefs.com/api/docs/limits-consumption)). [Free test queries](https://docs.ahrefs.com/api/docs/free-test-queries) exist for three of the vendor's own domains, but an API key is still needed "to run free test queries." The [changelog](https://docs.ahrefs.com/api/docs/changelog) is dated to the day; its newest entry on the day of reading was Nov 2, 2026.

**Ahrefs Connect**, [introduction](https://docs.ahrefs.com/ahrefs-connect/docs/introduction): "our integration program that lets third-party products access Ahrefs API data on behalf of Ahrefs users." The [OAuth guide](https://docs.ahrefs.com/ahrefs-connect/docs/oauth-guide) is authorization code with PKCE, scope `apiv3-integration-apps`, and "**No refresh tokens are issued.**"; "Access tokens are valid for" one year. Its [terms](https://docs.ahrefs.com/ahrefs-connect/docs/terms-of-service) require that "your App must be a publicly available product with an existing user base", and admission "are at Ahrefs’ sole discretion."

## Jobs: claimed, and declined

**`mkt.improve-search-visibility`, claimed.** This is the first claim on that job anywhere in the repository on the day of filing, and the claim is narrower than the vendor's. The MCP page's own sentence: "Ahrefs SEO MCP automates a wide range of SEO and marketing tasks like keyword research, competitive analysis, backlink audits, content planning, content gap analysis, on-page SEO recommendations, and so on." The pricing page: "Ahrefs’ plans help your business stay discoverable in search, AI, and beyond". The vendor's [use-case post](https://ahrefs.com/blog/mcp-use-cases/) lists fifteen prompts; the thirteenth asks the assistant to "increase organic traffic to [Site, e.g. Chewy.com] in a legitimate, whitehat way" and "Offer any advice you feel is appropriate."

What the entry does not say: that the product changes a page. No page read describes editing a title, a robots rule, structured data or a sitemap; Site Audit reports "projects, issues, page explorer, page content", and the job's text asks a claim to name "the surfaces the solution changes". The honest shape of this claim is an instrument: the vendor sells three of the job's five measures as reports (`gsc` for clicks and impressions, `site-audit` for pages a crawler can reach, Brand Radar for "real prompts with citations across multiple AI agents", per the [API introduction](https://docs.ahrefs.com/api/docs/introduction)), and an agent connected to it can read them before and after someone else's change. Mobile page performance is not named on any page read. Nobody outside the vendor has measured any of this. The job's own text excludes rankings from the claim; Rank Tracker is therefore described here and not claimed.

- `mkt.optimize-landing-page`, `mkt.draft-campaign-copy`, `mkt.personalize-email`: no page read names any of them. AI Content Helper, "Improve your content with AI.", is a menu line and was not read further.
