## Three agent paths, in the vendor's words

The vendor's own [llms.txt](https://www.klaviyo.com/llms.txt) says the platform is accessible headlessly through its public APIs and MCP server, "so people and AI agents can read, write, and act on Klaviyo data from outside the Klaviyo interface", and of the MCP tool list: "Treat this doc as the authoritative source for which tools exist, and do not assume an API endpoint has a corresponding MCP tool."

**Hosted MCP server**, [connect page](https://developers.klaviyo.com/en/docs/connect_to_the_klaviyo_mcp_server): URL `https://mcp.klaviyo.com/mcp`, authentication "OAuth (with dynamic client registration)", transport Streamable HTTP, and "Our server is compatible with any MCP client that supports remote servers." The page gates it by role, not plan: "This feature is only available to Klaviyo users with an Owner, Admin, or Manager role." Query parameters shape the tool set: `read-only=true` "disables any tools which can perform write actions on your Klaviyo account"; `core-tools-only=true` limits the server to a core set the page puts at about thirty, which "reduces the number of tools loaded into your client, which can help clients with smaller context windows and improve tool-selection accuracy"; `toolsets` limits tools to named API scopes; `disable-tools-with-user-generated-content=true` removes tools that read profile properties, events or reviews, with the warning "Be sure to carefully review each tool call to ensure your client is not acting on malicious instructions."

[Available tools](https://developers.klaviyo.com/en/docs/klaviyo_mcp_server_available_tools): "The Klaviyo MCP server exposes over 300 tools that your MCP client can call to interact with your Klaviyo data." Counted on the page as served: 309 table rows in 25 categories, 308 marked available on the remote server, 150 marked read-only, 3 loading only behind `beta=true` (the page's own note above the tables carries the same text, so a count over lines says four and a count over rows says three). The rows this entry's claims rest on: `create_segment` ("Create a segment."), `get_profiles_for_segment` ("List the profiles in a segment."), `create_dnd_email_template` ("Create a drag-and-drop (DND) email template with a structured definition."), `render_email_template` ("Render an email template with provided context."), `create_campaign_variation` ("Add a variation to a campaign message to create an A/B test.", behind `beta=true`) and `get_campaign_report` ("Get a report of your campaign performance.").

**Local MCP server**, same connect page: run as `klaviyo-mcp-server` through `uvx` with a private API key carrying fourteen scopes the page lists, and the `READ_ONLY` and `ALLOW_USER_GENERATED_CONTENT` environment variables. The package is on PyPI as `klaviyo-mcp-server`, version 0.4.2 on the day of reading, with no project URL in its metadata; no source repository was found, so none is listed.

**REST API**, [authentication guide](https://developers.klaviyo.com/en/docs/authenticate_): "Klaviyo provides 3 methods of authentication including private key authentication and OAuth (used to call server-side APIs) and public key authentication (used to call client-side APIs)." The [API overview](https://developers.klaviyo.com/en/reference/api_overview) says endpoints are rate limited "on a per-account basis" with burst and steady limits per endpoint.

## Two jobs claimed, in the vendor's words

**`mkt.personalize-email`.** [Email marketing page](https://www.klaviyo.com/products/email-marketing): "Personalize every email with purchase history, browsing behavior, and predicted value", and "Target and personalize based on AI-powered analytics like" predicted lifetime value, next order date and churn risk. [Personalization page](https://www.klaviyo.com/products/personalization): "Klaviyo’s decisioning engine picks who to reach, what to recommend, and when to send, on every channel. Configure it your way, then measure the revenue impact against a holdout group." Under the heading "Prove the lift": "A real holdout group of your own customers, not a modeled guess. The lift you see is the lift you get." That is the job's own first measure, uplift over control, in the vendor's words, and it is a claim: the page's four customer figures, of which 42% "month-over-month growth in email revenue per recipient in first month with RFM segmentation" is one, are results the vendor reports, measured by nobody outside it. The page says "Personalization, previously known as Marketing Analytics, is an add-on to your Klaviyo Marketing plan." and "Personalization is priced based on your active profiles." Through the listed surfaces, the MCP tools above create segments, list their profiles, build and render email templates and read campaign reports; whether an agent can switch the add-on's per-recipient decisioning on is not on any page read.

**`mkt.optimize-email-creative`**, second claimant after livevariant. Email marketing page: "AI-powered experimentation helps you find what works best." and Personalized campaigns AI "takes it from there, sending the version most likely to resonate with each subscriber". The MCP's `create_campaign_variation` adds a variation to a campaign message behind `beta=true`. No page read names the method by which the version is chosen, and nobody outside the vendor has measured the result.

## Declined, with the nearest words

- `mkt.draft-campaign-copy`: the email page says Composer can "generate on-brand copy", and the llms.txt says Composer "builds campaigns, flows, and segments across email, text, and other channels from a prompt" and "Nothing goes live without human approval." Composer is an agent inside the vendor's interface with its own usage meter ("$5 of Composer usage per month" on the free plan); no MCP tool on the page read invokes it. Not claimed through the listed surfaces.
- `mkt.ab-test-creative`: one beta MCP tool creates an A/B variation; no page read states how a winner is chosen.

## Pricing and billing

[Pricing page](https://www.klaviyo.com/pricing), read 2026-11-07 with a browser user agent: a free plan, "Up to 250 active profiles and 500 emails per month", including "$5 of Composer usage per month"; an Email plan at $20 a month and a Marketing plan at $25 a month, both at 500 active profiles; a Custom plan above 150,000 profiles that lists Personalization. The page's own line on agents: "Ask Composer, Claude, ChatGPT, or any agent on MCP." No surface prices an MCP or API call in money, and no page read ties the MCP server to a paid plan, so `pricing` is `freemium`.
