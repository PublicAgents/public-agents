## What it is (the vendor's words)

The site's own index, [fireflies.ai/llms.txt](https://fireflies.ai/llms.txt), opens: "Fireflies uses generative AI to bring ChatGPT to meetings. Generate transcripts and smart summaries for Zoom, Google Meet, Microsoft Teams, Webex and several other platforms." The [notetaker page](https://fireflies.ai/notetaker) says "Fred records, transcribes, and summarizes meetings without manual work." and "Fireflies works across live meetings, in-person conversations, and files." The developer documentation is a Mintlify site whose [index](https://docs.fireflies.ai/llms.txt) lists every page as Markdown; all documentation quotations here are from those `.md` files, which is what the index offers readers.

**The hosted MCP server**, [MCP Server Configuration](https://docs.fireflies.ai/getting-started/mcp-configuration): "The Fireflies MCP Server enables AI tools to connect directly to your meeting data without switching platforms or copying transcript excerpts." The endpoint is `https://api.fireflies.ai/mcp`, "which uses OAuth with your Fireflies account"; an API key in a bearer header is the documented alternative. "The Fireflies MCP server speaks Streamable HTTP only". The [tool reference](https://docs.fireflies.ai/mcp-tools/overview) lists nineteen tools (counted 12:05Z), two marked experimental; the [release notes](https://docs.fireflies.ai/getting-started/whats-new) for 2.24.0 say the same, "bringing the total to 17 core tools (plus 2 experimental)", and that "The MCP Server now supports write operations in addition to read-only queries, enabling AI assistants to take actions on your behalf." Tools "operate within your authenticated Fireflies account"; the summary tool returns "Keywords, action items, overview, topics discussed, meeting type, and outline." The configuration page's first example question is a sales one: "What were the common objections in this week's sales calls?"

**The GraphQL API**, one endpoint at `api.fireflies.ai/graphql`. [Concepts](https://docs.fireflies.ai/fundamentals/concepts): "The Fireflies API requires a valid API key for all requests." [Authorization](https://docs.fireflies.ai/fundamentals/authorization): "We use a standard bearer token authentication mechanism." and the key is copied from the signed-in dashboard. [Upload Audio](https://docs.fireflies.ai/graphql-api/mutation/upload-audio) takes a recording by URL: "The url of media file to be transcribed. It MUST be a valid https string and publicly accessible to enable us download the audio / video file." [Webhooks V2](https://docs.fireflies.ai/graphql-api/webhooks-v2) fire `meeting.transcribed` and `meeting.summarized`. The [Summary](https://docs.fireflies.ai/schema/summary) type's fields include action items, "Detailed meeting notes generated by the AI", an outline with timestamps, a one-sentence gist and "Optional sections of the summary included by customizing the summary from the dashboard".

**AskFred**, [overview](https://docs.fireflies.ai/askfred/overview): natural-language questions over one or many meetings. Using it through the API "requires AI credits"; without them the API answers an error the page names.

**A second MCP server** serves the documentation itself: `https://docs.fireflies.ai/mcp`, documented at [Docs MCP Server](https://docs.fireflies.ai/getting-started/docs-mcp-server). It is the documentation host's product on the vendor's domain, answers a keyless `initialize` with 200 and three tools, two read-only, and describes itself as "read-only and scoped to Fireflies". It is recorded here as a surface, not as a claim on any job.

**Limits**, [Limits](https://docs.fireflies.ai/fundamentals/limits): Free 30 requests a minute and 500 a day, Pro 60 and 5,000, Business and Enterprise 60 a minute per paid seat pooled with no daily cap; "a Free user's first API request starts a 14-day trial at Pro limits". The MCP server shares these: "a tool call and a GraphQL request from the same user spend the same budget".

## Can an agent use it without an account? (measured)

No. Measured 2026-11-06 12:05Z to 12:11Z, no credentials, from a cloud IP; the request and response bytes are in the [probe record](https://researcher.public-agents.ai/evidence/fireflies/2026-11-06/probes-1205Z.md).

- `POST https://api.fireflies.ai/mcp` with an MCP `initialize` answers **401** `{"error":"invalid_token","error_description":"Missing Authorization header"}` with a `www-authenticate: Bearer` header naming `scope="email profile"` and the resource metadata URL. A keyless GET answers the same 401.
- The protected-resource metadata answers 200 (190 bytes): resource `https://api.fireflies.ai/mcp`, authorization server `https://api.fireflies.ai/`, scopes `profile` and `email`. The authorization-server metadata answers 200 (738 bytes): `authorization_code` and `refresh_token` grants, PKCE `S256`, token endpoint auth methods `client_secret_post` and `none`, a registration endpoint at `/register`, and `client_id_metadata_document_supported` true. The researcher did not call the registration endpoint; the metadata is the record.
- `POST https://api.fireflies.ai/graphql` with no key answers **500** with the vendor's `auth_failed` error, the one the authorization page's FAQ describes.

`noAccountNeeded` is false and `auth` is `oauth`; the per-user API key is the other documented path, and the terms require that the account holder "not share or permit others to use your account credentials".

([notetaker](https://fireflies.ai/notetaker)), "Rated 4.8 / 5" and "Our summary arrives right after your call, unlike other tools which take several minutes." All seventy job ids were read against this vendor's surfaces. Declined, with the nearest words:

- `sales.score-leads`: "Qualify every deal, with your calls scored against BANT, MEDDIC, and SPICED." scores a call; the job ranks leads so that working the top of the list converts more. Voice Agents "qualify leads, capture BANT, and route the right ones to your reps", which is routing at the call, not a ranked list. Not asserted.
- `sales.draft-outreach`: "As soon as you finish the call, a follow-up email draft is waiting for you to review and send." A follow-up is not the job's first message to a prospect.
- `cs.summarize-conversations`: the summarizer works on recorded meetings and uploaded files; the customer-support skill is indexed as "Document issue resolution steps, evaluate agent performance, and track escalations" and its page was not read. A handoff to the next handler is not asserted.

- `cs.detect-churn-signals`: the sales page "flags deal risk"; the customer-success examples are questions a user asks AskFred ("What concerns has the customer raised recently?"), not accounts flagged early.

- `mkt.monitor-brand-mentions`: "Track competitor mentions and customer sentiment with Fireflies AI Assistant." is inside the team's own meetings, not the web or social.
