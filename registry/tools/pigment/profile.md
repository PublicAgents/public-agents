## Two agent paths, in the vendor's words

The vendor's [llms.txt](https://www.pigment.com/llms.txt) describes the product as "an AI-powered enterprise business planning and performance management platform for real-time planning, modeling, forecasting, analysis, and decision-making across finance, sales, HR, and operations."

**Hosted MCP server**, documented at [MCP Server](https://kb.pigment.com/docs/mcp-server-1) (page dated 2026-11-02 by the vendor). An administrator enables MCP in workspace settings, and a unique endpoint URL "is generated, which you will need to connect a third-party AI system to Pigment." "If you plan to connect multiple Workspaces, each must have its own MCP endpoint URL and connector." There is no public endpoint, which is why `surfaces.mcp` is null and nothing was sent. [Connect custom MCP Clients](https://kb.pigment.com/docs/connect-a-custom-application) requires "OAuth 2.1 with Dynamic Client Registration (DCR)" and says "API keys and other authentication methods are not supported."; the client's callback URL must be registered in the workspace first. The marketing page [Pigment MCP Server](https://www.pigment.com/ai/mcp-server) puts it as "Every session is authenticated through enterprise identity, and access is scoped by role, model, or metric." Data access is the user's own: the [MCP Server](https://kb.pigment.com/docs/mcp-server-1) page says "Only Metrics with the following data types can be read via MCP" (number, integer, boolean), and a per-block "AI data access" setting can hide data from the server.

[Supported tools](https://kb.pigment.com/docs/supported-tools) names two modes. "Public mode provides read-only tools for exploring and analyzing your Applications." "Advanced mode provides read and write tools for modeling and editing your Applications." and "Advanced mode is off by default." The vendor publishes skills in a [public repository](https://github.com/gopigment/ai-plugins), and the [Supported tools](https://kb.pigment.com/docs/supported-tools) page says of them: "Without them, AI systems lack the Pigment-specific knowledge needed to model reliably." The [tools and skills changelog](https://kb.pigment.com/docs/tools-and-skills-changelog) (dated 2026-11-06 by the vendor) lists 5 rows for November 2026 and 14 for October 2026: 12 marked New, 7 Deprecated, 3 of them skills rather than tools; tool names include `fetch_metric_data`, `get_metric_context`, `bulk_update_metrics` and `get_view_document`. The page does not give a total count of tools, and none is claimed here.

**REST API**, documented under [API Management](https://kb.pigment.com/docs/api-management) with an [OpenAPI document](https://pigment.app/api/swagger/external-api.swagger.json) that answers without credentials: title "Pigment External API", version `v1-external`, 25 paths (applications, blocks, views, data flows, imports, exports and files), one security scheme described as "API Key Authorization header using the Bearer scheme." Two things to keep apart: the commentary is produced by an agent inside the vendor's product, not through an MCP tool an outside agent calls, and the job's two measures (commentary accepted without rewrite, coverage of material variances) are reported by no surface read. The "cutting days" sentence is the vendor's, unmeasured. This is a claim, and the cell for its evidence is empty.
